# WorldBanc

A filesystem and shell scripting project created while working through the Learn Terminals and Shells course on Boot.dev.

The repository demonstrates organizing company information, product information, marketing ideas, and private operational data into a structured filesystem.

## Repository Structure

~~~text
worldbanc/
├── public/
│   ├── company_info.md
│   ├── pr_ideas.txt
│   └── products/
│       ├── accounts/
│       ├── cds/
│       ├── credit_cards/
│       ├── investments/
│       └── loans/
├── .gitignore
└── README.md
~~~

## Public Content

The `public/` directory contains information intended to be publicly accessible:

- Company information
- Marketing and public-relations ideas
- Product categories

## Private Content

The original project also contains a `private/` directory with operational files, customer records, transaction data, logs, scripts, and a key file.

The entire `private/` directory is excluded from version control and is intentionally not included in this public repository.

## Purpose

This project was created to practice filesystem navigation, directory organization, file permissions, shell scripting, and working with structured project data.
